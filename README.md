# fnaf-in-python-shell
this project is a small passion project which I wanted to make for fun.

It was initially made in Python 3.4.3 and is my first large project I made from scratch.
It is 12.9 KB and 477 lines of code of poorly optimised code.

It runs completely in terminal & has a few tiny Easter Eggs hidden inside.

I haven't created a power system so the doors will just open when the penalty counter rolls higher than the limit.
